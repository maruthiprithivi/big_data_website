What stays, what changes

Preserved exactly

  • All section text & descriptions
  • All technology links & references
  • Kafka lab instructions & git URLs
  • Decision flowchart (ReactFlow stays)
  • Schema FK/PK hover interactions
  • MapReduce step-by-step animation logic
  • Spark step animation logic
  • All existing interactive state

Redesigned

  • All colors → Warm Notebook palette
  • Dark bg → cream #FAFAF7
  • Neon text → warm neutrals
  • Nav tabs → horizontal TOC + accordion
  • Diagram layouts → flexbox flow (no pixel offsets)
  • Diagram arrows → CSS borders/pseudo-elements
  • No SMU/IS459 references anywhere
  • Kafka content added as new section 04
